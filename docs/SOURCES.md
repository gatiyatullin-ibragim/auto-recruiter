# Источники вакансий

| Источник | Способ доступа | Статус |
|---|---|---|
| Demo | Локальный fixture, без сети | Включён для разработки |
| hh.kz / hh.ru | Официальный API после регистрации приложения | Требуются OAuth credentials |
| Remotive | Публичный API при соблюдении лимитов | Требуется отдельный адаптер |
| LinkedIn | Не подключается | Запрещён в рамках проекта |
| Indeed | Не подключается | Запрещён в рамках проекта |
| Glassdoor | Не подключается | Запрещён в рамках проекта |

Перед включением любого сетевого источника нужно проверить актуальные ToS,
robots.txt, лимиты и требования User-Agent.
