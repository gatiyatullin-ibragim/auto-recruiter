# Архитектурные решения

## 2026-10-24: вертикальный срез профиля перед внешними интеграциями

Сначала реализуется и проверяется локальный сценарий профиля: резюме, имя,
желаемая позиция, локация и формат работы. Внешние API вакансий, LLM и отправка
откликов не подключаются без отдельных адаптеров и моков.

Причины:

- внешние ключи и OAuth не нужны для локальной разработки;
- бизнес-правила формы можно проверить детерминированно;
- запрещено имитировать успешную отправку наружу;
- каждый источник вакансий должен пройти отдельную проверку документации и ToS.

До появления фоновой search-задачи кнопка поиска сохраняет валидный профиль, но
не выполняет внешних запросов и не обещает отправку откликов.
